# Installation

Green Thumb is installed by soldering its four pads to the matching points on the LED board. Nothing else on the device is modified.

| Flex pad | Solders to |
|---|---|
| GRN_SGNL | green control point |
| BLU_SGNL | blue control point |
| BTN | button point |
| GND | ground point |

1. Seat the flex so each pad sits over its point.
2. Solder the four pads.
3. Check there are no solder bridges between neighbouring pads.

Then see [testing.md](testing.md) to confirm it works.
